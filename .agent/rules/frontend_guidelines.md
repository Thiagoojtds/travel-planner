# Diretrizes de Frontend

- Utilizar Vanilla CSS em `src/styles/index.css`.
- Cores temáticas escuras com glassmorphism (slate, cyan, emerald, amber, rose).
- Tabelas sempre com `white-space: nowrap` para não quebrar valores ou rotas.
- Modais preservam rascunho ao fechar no backdrop e resetam apenas no submit.
